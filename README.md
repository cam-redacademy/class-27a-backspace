# class-27a-backspace
redAcademy Class 27A — Backspace Technologies Python Track

This repo is where Class 27A submits Python assignments. Follow the steps below exactly — they're the same steps used in real software teams.

## Setup (do this once)

1. **Fork this repo** — click the "Fork" button top-right of this page. This creates your own copy at `github.com/YOUR-USERNAME/class-27a-backspace`.
2. **Clone your fork** to your computer:

git clone https://github.com/YOUR-USERNAME/class-27a-backspace.git
cd class-27a-backspace


## Submitting an assignment

1. Create a new branch named after yourself and the assignment:

git checkout -b student/your-name-assignment1

2. Add your code, then commit:

git add .
git commit -m "Assignment 1: short description"

3. Push to **your fork**:

git push origin student/your-name-assignment1

4. On GitHub, open your fork → click **"Compare & pull request"** → make sure it's comparing your branch against `redAcademy's main branch` → submit the PR.
5. Wait for feedback/merge from the instructor.

## Rules
- One pull request per assignment.
- Include your name and assignment number in the PR title.
- Do not push directly to `main` — it's protected and will be rejected.

## Getting your fork up to date
Before starting a new assignment, sync your fork with the latest changes:

git checkout main
git pull https://github.com/ORIGINAL-OWNER/class-27a-backspace.git main
git push origin main

Replace ORIGINAL-OWNER with your GitHub username. Commit directly to main (there's a "Commit directly to the main branch" option at the bottom of the page).
